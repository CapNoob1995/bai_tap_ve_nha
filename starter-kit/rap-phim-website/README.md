# CineBox – Đặt vé xem phim mini.

Website **đặt vé** *xem phim mini*.

| Thư mục | Nội dung | Chú Thích |
| :--- | :--- | :--- |
| `src/` | Mã nguồn chính của ứng dụng | Chứa các tệp HTML, CSS, JavaScript |
| `assets/` | Tài nguyên giao diện | Lưu trữ hình ảnh, icon và font chữ |
| `docs/` | Tài liệu dự án | Chứa báo cáo và tài liệu hướng dẫn |


## Lệnh hệ thống
```powershell
Get-ChildItem -Path -Force
```
